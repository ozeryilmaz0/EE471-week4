MediaPipe Solutions is a set of libraries and tools from Google for applying machine learning in applications. It runs on Android, iOS, the web and desktop with Python. Each solution, such as the face landmarker or the text classifier, comes with a ready-to-use model and a simple task API. Developers can load a model file, pass an image, an audio clip or a piece of text, and get structured results back in a few lines of code. Many models run fully on the device, so user data does not have to leave the phone or the computer. This keeps latency low and helps privacy. With MediaPipe Model Maker, developers can also retrain some models on their own data, for example to recognise new hand gestures or new object classes.
